Nice Trojmiasto
Last updated / Ostatnia aktualizacja: 2026-04-26

PL

Rozszerzenie Nice Trojmiasto działa na stronach artykułów trojmiasto.pl i pomaga filtrować komentarze.

Jakie dane są przetwarzane:

  • treść komentarzy i ograniczony kontekst artykułu (np. tytuł, lead, fragment tekstu),
  • ustawienia rozszerzenia zapisane lokalnie w przeglądarce,
  • dane diagnostyczne/cache analizy przechowywane lokalnie.

Cel przetwarzania: klasyfikacja komentarzy i prezentacja wyniku w interfejsie rozszerzenia.

Udostępnianie danych: dane wymagane do analizy są wysyłane do OpenAI API (https://api.openai.com). Rozszerzenie nie używa własnego backendu pośredniczącego.

Przechowywanie i kontrola: dane cache i ustawienia są przechowywane lokalnie; użytkownik może je usunąć przez ustawienia przeglądarki/rozszerzenia.

Bezpieczeństwo: komunikacja z API odbywa się przez HTTPS; klucz API użytkownika jest przechowywany lokalnie.

Kontakt: mickurzelewski@gmail.com

EN

Nice Trojmiasto is a browser extension for trojmiasto.pl article pages that helps filter comments.

What data is processed:

  • comment text and limited article context (for example: title, lead, excerpt),
  • extension settings stored locally in the browser,
  • locally stored analysis cache/diagnostic data.

Purpose: comment classification and displaying results in the extension UI.

Data sharing: data required for analysis is sent to OpenAI API (https://api.openai.com). No separate publisher-owned proxy backend is used.

Retention and user control: cache and settings are stored locally and can be removed by the user at any time.

Security: API traffic uses HTTPS; the user's API key is stored locally in extension storage.
